## Code found under ,,blanotes.py''


BlaNotes is the reason why most computer programs even exist. Let me explain...

Ever had this situation: you're just coding as usual and have a quick idea for a feature, and you want to save it somewhere you can see it right away?
Most people would use a 3rd party tool like Notion, Apple Notes, etc.

Just use BlaNotes — it lives in your terminal, you can just write quick notes and view them when needed...

## Commands

/history - View your past notes

/delete - Select irrelevant notes to delete them

/download - Export your notes as an .txt File

/help - View the Command List 

/exit - Quit the programm

/github - opens GitHub Repository on browser

/font - change Font Style: Italic,Bold,Underline
## Activate BlaNotes

BlaNotes runs natively,so now download is required,

 - Create New File named: blanotes.py
 - Paste the latest BlaNotes Code
 - Return to your code and enter this command...
    
       python blanotes.py

## Why BlaNotes?

Unlike other platforms we value your code and ofcourse your Privacy, BlaNotes does not run on an large Cloudbase, it runs on your device
